# TMI Stages Trainer

A study app for Stages 1–6 of *The Mind Illuminated* by Culadasa (John Yates): Train, Grill (multiple choice), Test (open answers, self-marked) and Scenario (diagnose a student's report).

Intended for students who own and have worked with the book.

## Files
- `index.html`: the app
- `data.js`: original question banks and training notes
- `extra.js`: expanded banks (Grill, Test, Scenario), numbered by position in each stage's source file

Progress and field-test feedback are saved in each visitor's own browser. Use **Export feedback** in the app to send feedback back.

Live site: https://charliewhynot-pixel.github.io/tmi-stages-trainer/
